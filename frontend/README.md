# 💻 Frontend - Library Management System

This is the React + Vite frontend client for the Library Management System.

## 🚀 Running the Frontend Locally

```bash
# 1. Install dependencies (if not already installed)
npm install

# 2. Run the development server
npm run dev
```

The frontend will run at: `http://localhost:5173`

## ⚙️ Configuration
The frontend automatically connects to `http://localhost:5000/`.
If you ever change your backend port or URL, configure it in `.env`:
```env
VITE_BACKEND_URL=http://localhost:5000/
```
